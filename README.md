# 📱 Quiz App + Login System (Firebase)

This is a simple Android app with a basic login/register system for **students and teachers**, and a quiz module connected with Firebase.
Nothing fancy, just trying to make things work properly 😄

---

## 📌 What this project does

- Student registration & login using Firebase Auth
- Teacher registration & login using Firebase Auth
- Separate navigation for student and teacher
- After login, user goes to quiz or dashboard screen
- Basic validation for empty fields and password mismatch
- Firebase Firestore setup for future quiz data handling

---

## 🧭 Flow of the app

### 👨‍🎓 Student side
- Register → Login → Quiz screen

### 👨‍🏫 Teacher side
- Register → Login → Dashboard

## 🧩 Firebase setup

Make sure Firebase is connected properly:

- Enable **Email/Password Authentication**
- Add `google-services.json` in app folder
- Sync Gradle properly (don’t skip this or it will cry)
